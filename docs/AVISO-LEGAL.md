# Aviso legal

Este projeto é software livre, distribuído sob licença MIT (veja [LICENSE](../LICENSE)), "como está", sem garantia de nenhum tipo.

## O que isso significa na prática

- **Não operamos nenhuma VPS.** Este repositório contém scripts que você roda na *sua própria* VPS, contratada em *seu próprio* nome, com *seus próprios* dados de pagamento (inclusive em planos gratuitos). Não hospedamos, não administramos, não temos acesso a nenhuma instância rodando este código.
- **Não somos um serviço de VPN.** Não existe "conta FuraBloqueio", não coletamos tráfego, não vemos seus dados. A VPN sobe inteira dentro da VPS que você controla.
- **Você é responsável pelo uso.** Como qualquer ferramenta de rede/privacidade, o uso adequado é sua responsabilidade — inclusive cumprir as leis aplicáveis ao seu país/estado.
- **Sem garantia.** Não garantimos disponibilidade, segurança absoluta ou adequação a qualquer finalidade específica. Os scripts foram revisados e testados (veja o histórico do repositório), mas software tem bugs — não há promessa de funcionamento livre de falhas.
- **Sem responsabilidade por danos.** Na máxima extensão permitida por lei, os autores e contribuidores deste projeto não se responsabilizam por danos diretos ou indiretos decorrentes do uso deste software — mesma cláusula padrão de qualquer projeto MIT (veja [LICENSE](../LICENSE)).

## Isso é uma ferramenta de privacidade pessoal

O objetivo deste projeto é permitir que qualquer pessoa hospede sua própria VPN pessoal, do mesmo jeito que faria com um servidor de e-mail ou de arquivos próprio — controle sobre seus próprios dados, sem depender de provedor terceiro. Como qualquer ferramenta de rede (VPN comercial, Tor, DNS alternativo), o que você faz com ela é decisão e responsabilidade sua.

Se você tem dúvida sobre a legalidade de um uso específico no seu contexto, consulte um advogado — este documento é uma explicação de escopo do projeto, não aconselhamento jurídico.
